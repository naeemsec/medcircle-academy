# Version 2 — medical learning and live Zoom courses

- Renamed the academy to MedCircle and replaced coding content with medical education content.
- Preserved the responsive layout approach and small animations, with a medical teal/pastel theme.
- Replaced recorded course lessons/progress with scheduled live Zoom lectures.
- Added per-course price/currency, payment submissions, review decisions and course access.
- Added private payment screenshots and configurable external payment instructions.
- Protected Zoom URLs on the server; only approved members of the corresponding course can retrieve them.
- Added public and course-private notices with pinning and in-app unread indicators.
- Added student payment status, approved course dashboard and lecture schedule.
- Added admin lecture, notice, payment approval/rejection/revocation and payment-setting controls.
- Kept account management, course management, reel uploads, likes and student management.
- Uses a new medcircle.sqlite database; the old coding database is not automatically migrated.
